# Конфигурация окружения

Документ описывает переменные окружения, используемые сервисами Next Best Offer.
Все значения задаются в файле `.env` (см. пример `.env.example`).

## Обязательные параметры

| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `POSTGRES_DSN` | `postgresql://nbo:nbo@postgres:5432/nbo` | Строка подключения к PostgreSQL. Используется API и воркерами. |
| `REDIS_URL` | `redis://redis:6379/0` | Подключение к Redis для кэша и очередей. |
| `FEAST_REPO_PATH` | `/opt/feast_repo` | Путь до репозитория признаков (Feast). Общий для API и ML-пайплайна. |
| `MODEL_REGISTRY_PATH` | `/opt/models` | Каталог с моделями ALS/LightGBM. |

## Общие настройки сервиса

| Переменная | По умолчанию | Назначение |
|-----------|--------------|-----------|
| `ENVIRONMENT` | `local` | Метка среды (отображается в логах и метриках). |
| `LOG_LEVEL` | `INFO` | Уровень логирования (`DEBUG`, `INFO`, `WARN`, `ERROR`). |
| `API_HOST` | `0.0.0.0` | Адрес, на котором слушает FastAPI. |
| `API_PORT` | `9090` | Порт HTTP API. Используется также в `docker-compose.yml`. |
| `METRICS_PORT` | `9091` | Порт экспорта метрик Prometheus внутри API контейнера. |
| `TRACING_ENDPOINT` | _(пусто)_ | gRPC/HTTP endpoint для отправки трассировок OpenTelemetry (например, Jaeger OTLP). |

## Настройки базы данных

| Переменная | По умолчанию | Назначение |
|-----------|--------------|-----------|
| `DB_ECHO` | `false` | Включает SQLAlchemy echo для отладки запросов. |
| `DB_POOL_SIZE` | `10` | Размер пула соединений. |
| `DB_MAX_OVERFLOW` | `20` | Дополнительные соединения сверх пула. |
| `DB_POOL_TIMEOUT` | `30` | Таймаут ожидания соединения (сек). |

## Очереди и Celery

| Переменная | По умолчанию | Назначение |
|-----------|--------------|-----------|
| `CELERY_BROKER_URL` | `redis://redis:6379/0` | Брокер задач (можно заменить на RabbitMQ). |
| `CELERY_RESULT_BACKEND` | `redis://redis:6379/1` | Хранилище результатов задач. |
| `CELERY_TIMEZONE` | `UTC` | Таймзона планировщика. |
| `CELERY_DEFAULT_QUEUE` | `nbo_default` | Базовая очередь для задач. |
| `CELERY_IMPORTS` | `services.workers.tasks.events_ingest,services.workers.tasks.recommendations` | Дополнительные модули для автозагрузки задач. Формат — CSV. |

## Параметры ML и бизнес-логики

| Переменная | По умолчанию | Назначение |
|-----------|--------------|-----------|
| `ALS_FACTORS` | `64` | Размер факторизации модели ALS. |
| `ALS_REG` | `0.1` | Регуляризация ALS. |
| `LGBM_MODEL_PATH` | `/opt/models/lgbm.bin` | Путь до бинарной модели LightGBM. |
| `NBO_RETRY_WINDOW_SECONDS` | `30` | Интервал повторного запроса рекомендаций. |
| `EVENT_IDEMPOTENCY_WINDOW_SECONDS` | `600` | Временное окно идемпотентности событий. |
| `AB_VARIANTS` | `control,treatmentA` | Список вариантов A/B экспериментов (CSV). |

## Переменные для инструментов

| Переменная | По умолчанию | Назначение |
|-----------|--------------|-----------|
| `PERF_TARGET_HOST` | `http://api:9090` | Целевой хост для Locust (docker profile `perf`). Переопределяйте при запуске из вне docker-compose. |

## Рекомендации по использованию

- Значения, содержащие пробелы или спецсимволы, заключайте в кавычки.
- Для продакшена используйте секрет-хранилища (Vault, AWS Secrets Manager).
- После изменения `.env` перезапускайте контейнеры: `docker compose up -d --force-recreate <service>`.
- Документация обновляется одновременно с изменением `.env.example`. Проверяйте README и quickstart.
